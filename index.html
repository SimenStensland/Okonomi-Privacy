About this application

This is a personal finance application built and operated by Simen Stensland for his own private use. It is not offered to any other users or third parties.

Data we access

The application uses Enable Banking to read account balances and transactions from the owner's own bank accounts, after the owner has given consent through their bank.

How data is used

The data is used only by the owner for personal bookkeeping and budgeting. It is not shared with, sold to, or disclosed to any third party.

Storage and security

Data is stored in systems controlled by the owner. API keys and credentials are kept secret and are never exposed in client-side code.

Retention and consent

Bank consent is given for a limited period and can be revoked at any time through the bank. Stored data can be deleted by the owner at any time.

Terms of use

The application is provided for the owner's personal use only, without any warranty. No other person is granted access or user rights.
